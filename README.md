# Full-Stack Developer Portfolio

A modern, animated portfolio website with a clean blue & emerald color theme, featuring smooth animations, 3D cursor effects, and human-touch interactions.

## ✨ Features

- **Modern Design** - Blue & Emerald color scheme with clean aesthetics
- **3D Cursor Effects** - Interactive cursor with trails, particles, and magnetic effects
- **Smooth Animations** - Organic movements, breathing effects, and playful interactions
- **Fully Responsive** - Works perfectly on all devices
- **Human Touch** - Casual language, wiggling emojis, and friendly animations
- **Performance Optimized** - Fast loading with efficient animations

## 📁 Project Structure

```
portfolio/
├── index.html          # Main HTML file
├── style.css           # All styles (combined)
├── main.js             # All JavaScript (combined)
├── open-portfolio.bat  # Quick launcher for Windows
└── README.md           # This file
```

## 🚀 Quick Start

### Option 1: Double-click to Open
Simply double-click `open-portfolio.bat` to open the portfolio in your default browser.

### Option 2: Manual Open
1. Navigate to the portfolio folder
2. Right-click `index.html`
3. Select "Open with" → Your browser (Chrome, Edge, Firefox, etc.)

### Option 3: Live Server (Recommended for Development)
If you have VS Code with Live Server extension:
1. Open the portfolio folder in VS Code
2. Right-click `index.html`
3. Select "Open with Live Server"

## � Customization

### Update Personal Information

Edit `index.html` and update:
- **Line 78**: Greeting text
- **Line 80-82**: Your title/headline
- **Line 84-86**: Your description
- **Lines 91-112**: Your stats (years, projects, clients)
- **Lines 130-147**: Tech stack icons

### Change Colors

Edit `style.css` (lines 1-74) to modify:
- `--color-primary`: Main blue color
- `--color-secondary`: Emerald/green color
- `--color-accent`: Purple accent color
- `--gradient-primary`: Main gradient

### Update Projects

Edit `index.html` starting at line 320 to add/modify your projects.

### Update Experience

Edit `index.html` starting at line 428 to update your work history.

### Update Contact Info

Edit `index.html` starting at line 500 to change:
- Email address
- Phone number
- Location
- Social media links
